## Overview

Canyon Kudos gives teams a shared, organized way to recognize employees. Recognition can be linked to the organization's core values, making individual contributions easier to highlight throughout the workplace.

In addition to collecting kudos, the application offers a TV presentation mode and supports quarterly drawings. Recognition can therefore be shared with a broader group instead of remaining visible only to the person who submitted it.

---

## What It Provides

- Capture and distribute employee recognition.
- Tie kudos to the organization's core values.
- Show recognition entries on a TV screen.
- Facilitate quarterly recognition drawings.
- Run through a web browser.
- Maintain a shared hub for recognition activity.
- Help make appreciation a regular workplace practice.

## Installation and Local Setup

Retrieve the repository, then move into the project directory:

```bash
git clone https://github.com/noahzgstone8275/canyon-kudos-recognition-hub.git
cd REPO
```

Canyon Kudos is a web application. Serve its files through a local static server, or open the primary HTML file in a browser. If Python is available, you can start a server with:

```bash
python3 -m http.server 8000
```

Open the application at:

```text
http://localhost:8000
```

To use the hosted edition, open the [latest build](https://noahzgstone8275.github.io/canyon-kudos-recognition-hub/).

## Getting Started

1. Launch Canyon Kudos in a modern web browser.
2. Submit new recognition or browse existing entries.
3. Assign the appropriate core value to each recognition item.
4. Switch to the TV display view when kudos should be visible to a larger audience.
5. Use the collected recognition while organizing a quarterly drawing.
6. Continue adding kudos as new recognition is submitted.
